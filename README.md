The application supports resumable onboarding, shared capacity calendars, queued mock curriculum generation, versioned editing and coordinator approval. The AI gateway includes two provider-specific adapters tested with simulated HTTP responses; live providers remain disabled. Identity/directory adapters are mocked and notifications do not deliver email. This is not a live deployment or a completed learning platform.
