What changed

The client screen now follows the approved reference structurally: Client directory and Account access tabs, one search/status/clear row, result count, sortable name column, initials and identity, status badges, effective member/admin counts, and a Manage client action. Management forms open in native modal dialogs. Mobile tables become labelled stacked cards.

The same table spacing, headers, row separators, badges and actions now apply to account access, Global Admins, administrative audit, People, people assignments, appeals, promotion and sensitive-access lists, issued account links, assessment library/assignments, alternate reviewers and the review queue. Forms retain their existing server actions and safeguards.

The app retains its platform/client theme and real identifiers and data. The mockup's synthetic records and short sample IDs were not copied into application data.

Corrections found during verification

  • Stable search-field identity prevents focus loss during live filtering.
  • Enter refreshes the search instead of clearing it.
  • Search, select and action controls align at the same height.
  • Mobile users retain access to name sorting when table headings are hidden.
  • Dialogs close with Escape or Close and return focus to their opener.
  • Failed forms can reopen their relevant dialog; error links can reveal a closed dialog.
  • Used or cancelled account links show no available action instead of opening an empty dialog.
  • Client counts use effective memberships and eligible identities; future, inactive and expired access is excluded. Suspended clients report zero effective members/admins.
