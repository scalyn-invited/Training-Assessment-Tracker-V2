# Task handoff template

Copy to a uniquely named file under `handoffs/`. Replace every unknown with actual evidence or explicitly `unknown/not_run`; leave approval fields unfilled until the real reviewer acts.

- Date/time and timezone:
- Author / contributor / applicable review owner:
- Task ID and bounded slice:
- Branch/worktree and exact commit or dirty-state description:
- Requirement IDs and PDF sections:
- Accepted decisions and contract versions consumed:
- Changes and affected files:
- New/changed contracts, compatibility and consumer impact:
- Database migration/backfill/rollback requirements:
- Checks: command/scenario, environment, result and evidence path:
- Permission/negative-path evidence:
- UI visual/accessibility evidence when applicable:
- Historical evidence reused, with explicit limits:
- Blocked/not-run/live dependencies and actual owner:
- Cost/live-operation authorisation reference if applicable:
- Remaining work and next ready task for author:
- Requested next action for Bernie, Saturnino or project owner:
- Shared files released or still reserved:
- Actual hours if known / remaining estimate and reason:
- Technical self-review status (Bernie-owned work):
- UX/accessibility review status (applicable user-facing work):
- Project-owner milestone acceptance: pending / accepted with reference.

Bernie writes a separate technical self-review when required. Saturnino writes a separate UX/accessibility review when applicable. Only the project owner can record milestone acceptance. Neither a template nor the producer can supply another person's decision.
