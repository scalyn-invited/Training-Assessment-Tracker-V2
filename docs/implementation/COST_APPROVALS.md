# Paid services and live operation approvals

Maintainer: Bernie. **No additional cost or live-operation approval is recorded in this package.** This is not a claim that the organisation has no subscriptions; verify actual entitlements without exposing credentials. Only an actual authorised human instruction establishes approval.

## Services to evaluate before commitment

| Category | Cost drivers / approval needed |
| --- | --- |
| AI calls | Provider/model, region/data, input/output/retry usage, task/client and total monthly caps; no automatic higher-cost fallback. |
| Hosting/staging | Compute, workers, MariaDB, storage, bandwidth, domain/SSL options and operational maintenance. |
| Backups/monitoring | Offsite retention, restore traffic, log volume, alerts and recovery ownership. |
| SMTP | Sender/domain, monthly volume, monitoring/features and actual delivery evidence. |
| Cerebru/IdP/API | API/SSO tiers, accounts/seats and connector licensing; verify existing entitlement. |
| OCR/scanning/documents | Chosen licence/support terms; any managed or commercial service requires approval. |
| Reports/branding | Premium charts/exports/BI, fonts/assets and custom-domain costs. |
| Search/developer tooling | Vector hosting/embeddings, CI minutes/storage and additional developer or AI tool seats. |

## Approval request template

```text
Request ID: COST-YYYYMMDD-short-slug
Status: proposed (never prefill approved)
Prepared by / milestone / purpose:
Provider, exact service/model/tier, region and current quote URL/date:
Existing entitlement and lower-cost alternative:
One-time amount / currency / tax:
Expected recurring amount / worst case / hard cap:
Usage assumptions, retries, data classes and retention:
Licence, renewal, cancellation and accountable owner:
Specific requested action (purchase, provision, paid test, enable recurring usage):
Actual approver, date and source instruction: not supplied
Approved scope and limits: none recorded
Evidence / follow-up:
```

Preparing a quote, using a free trial, receiving credentials or writing a template does not approve spending or data use. Approved spending does not automatically approve production deployment, real staff-data access or notifications. Track those operation scopes separately. If existing session authorisation already covers the action, record it and proceed within its limits; do not ask again merely because this file previously had no entry.
