## Cross-cutting proposal

Use internal opaque IDs and client/environment scope on all training records. Resolve actor and scope on the server, never from browser-supplied client/member authority. Restrict data before search, pagination, totals, AI context and exports; recheck at background execution, publication, response and download. Cache keys include identity/client/environment and permission/source versions. Imported stale privileged/external access fails closed; the actual external freshness contract awaits D03.

Proposed failure semantics retain repository guidance: 401 invalid authentication, 403 absent operation capability, 404 inaccessible object, 409 stale version/idempotency/freeze conflict, 503 stale permissions/unavailable dependency. C01/C02 acceptance must establish where each applies; do not leak existence in denial bodies. Mutations carry exact expected versions and audited human reasons; asynchronous requests bind idempotency key to payload hash and actor/scope. A replay with different content conflicts. Lists expose only scoped counts and stable paging. These semantics require fixture review before implementation.
