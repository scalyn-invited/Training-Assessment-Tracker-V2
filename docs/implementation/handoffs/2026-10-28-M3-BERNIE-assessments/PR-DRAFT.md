# Add assigned initial assessments with evidence-linked human review

Coordinators can publish reusable assessment definitions, assign them to authorised members, and review immutable responses independently of programme lessons. Members can recover saved drafts, upload private evidence, submit attempts, resubmit after rejection, and view only human-approved results.

The change adds versioned C03 contracts, configurable rubrics with application-computed totals, confirmed file evidence, exact-version decisions, alternate-reviewer appeals and synthetic-only provisional AI through the existing gateway. Existing client permissions, file quarantine and localhost live-service restrictions remain enforced. M4 plan generation is unavailable until its own implementation.

Validation and activation evidence: see the companion M3 handoff. Local checks do not establish hosted CI, calibrated live AI, Saturnino's UX/accessibility approval or project-owner milestone acceptance.

Remote publication and merge are not performed by this delivery.
